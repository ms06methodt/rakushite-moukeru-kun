# 🚀 俺専用ビットコイン自動運用アプリ『楽して儲ける君』

> **「知識ゼロ・完全自動・執事にお任せ」**  
> ユーザーはAI執事からの「2択の相談」に答えて育成するだけ。  
> デモ運用で学習が完成したタイミングで、Coincheckの実弾取引へシームレスに移行するオレ専用クリプトファンドマシン。

---

## 🌟 主な機能と特徴

### 1. 漆黒＆ネオンのサイバー・ダッシュボード（UI/UX）
- **複雑なローソク足チャートは完全排除**: 中央に巨大なネオン文字で「現在のトータル利益（+〇〇円）」のみを表示。
- **3大AIポケット稼働状況**:
  - **A: 堅実ロボ**（ボリンジャーバンド逆張り＆RSI防御・低リスク高勝率）
  - **B: AIデイトレ**（Gemini超短期スキャルピング・モメンタム追従）
  - **C: コピートレード**（100BTC超のオンチェーン大口クジラ追従）
- **ネオン・クイックコマンド**:
  - ⚡「直近5分の利益は？」
  - 💰「今日のトータルは？」
  - 🔮「今の相場を一言で」

### 2. AIの脳内スケルトン化＆2択育成システム
- **AIの思考プロセス・反省ログ**: トレード理由や勝率、確信度（0〜100%）をリアルタイム可視化。
- **2択改善提案**: 難しいパラメータ設定は不要。AIからの「【A】か【B】」の提案をタップするだけで、次回の売買プロンプト・戦略ロジックが自動チューニング。

### 3. ノイズキャンセリング＆パニック防止防御
- 日常の些細な変動では無音。
- 24時間で5%以上の急落を検知した時のみ、中学生レベルの分かりやすい解説と「ご主人様は放置で問題ありません」という結論をセットにした防御アラートを表示。

### 4. デモから実弾投入へのシームレス移行
- 初期はワンコイン（500円）〜数万円の仮想資金によるシャドートレード。
- 勝率や利益率が一定の基準を満たすと、AI執事から「実弾投入のご提案」イベントが発生。
- GOサインでCoincheck API（キルスイッチ付き）を有効化し、本番トレードへ昇格。

## 🛠️ 起動方法

## ⚙️ APIキー設定（任意）
アプリ内の右上の **「⚙️ 設定」** から以下を設定可能です：
1. **Google Gemini API Key**: より高度な自然言語対話やセンチメント分析を有効化（未設定時も内蔵の執事知能エンジンが完全自動応答します）。
2. **Coincheck API Key / Secret**: 実弾運用時に使用。
3. **緊急停止キルスイッチ**: いつでもワンタップですべての売買を完全ブロック可能。
